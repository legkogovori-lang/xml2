Инструменты, которые упрощают работу с электронной транспортной накладной

Встроенная база данных

Храните грузоотправителей, перевозчиков, водителей и транспорт в IndexedDB. Быстрый доступ без потери данных.

Поддержка отсеков

Добавляйте неограниченное количество отсеков с разными продуктами, плотностью, температурой и маркировкой.

Умный поиск

Автодополнение при вводе — выбирайте контрагентов из базы, все реквизиты подтянутся автоматически.

Экспорт и импорт

Выгружайте справочники в JSON и переносите между устройствами. Резервное копирование в один клик.

Готовый XML для ЭДО

Генерация файла строго по схеме 5.01 титула Т1, подходит для загрузки любому оператору ЭДО.

Локальная работа

Все данные хранятся в вашем браузере. Никаких серверов — только вы и ваша база.

Как это работает

Три простых шага до готового XML для ЭДО

1

Наполните базу

Добавьте ваших контрагентов, водителей и транспорт в удобные формы.

2

Заполните накладную

Выберите участников из списка, укажите отсеки с грузом и параметры перевозки.

3

Скачайте XML

Нажмите кнопку — файл готов к загрузке оператору ЭДО.

Мы НЕ собираем и НЕ храним ваши данные на своих серверах. Вся информация (контрагенты, накладные, настройки) сохраняется исключительно в локальном хранилище вашего браузера (IndexedDB). Никакие данные не передаются на внешние серверы.
